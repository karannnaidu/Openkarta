Why open matters here.

Agentic commerce will route trillions of dollars in the next decade. If a single closed SDK owns the contract between agents and merchants, it owns the economy. OpenKarta is the alternative.

01

MIT, forever

The spec, the SDK, the reference agents, the conformance harness — all MIT. Fork it, embed it, ship it. No proprietary surface to negotiate around.

02

Multi-language by design

Today: Node SDK. Tomorrow: any language with HTTP and HMAC. The protocol is the contract — not the SDK. Implementations follow.

03

Federated registry

Agents register themselves to a public, version-controlled list. No gatekeeper, no platform fee, no “preferred partner” tier.

04

Signed, not trusted

Quote tokens are HMAC-signed end-to-end. Conformance badges are HMAC-signed. Merchants never re-price between quote and checkout.

One contract. Every category.

The 8 verbs

discoverRead a merchant's capabilities manifest
searchDiscriminated query by item type
getSingle-item lookup
quotePrice a homogeneous cart, get a signed token
checkoutPlace an order against the signed quote
statusRead order + fulfilment state
cancelCancel an order with reason
returnInitiate a refund

The 5 item types

  • productphysical or digital goods — instant, same-day, scheduled, pickup, standard
  • stayhotels, homestays, apartments, villas, hostels — multi-night booking
  • flightair travel with carriers, fare classes, baggage
  • businter-city bus with operators, seat classes, boarding
  • serviceappointments at-customer, at-provider, online, or venue

Carts are homogeneous: every line shares the same itemType.

Three ways to participate.

Lite
~1 hour

Publish a markdown table at a public URL. We crawl it, host it, route discoveries to you.

For the corner shop with a Google Sheet.

HTTP
~1 day

Implement the eight verbs over HTTPS. Get full quote, checkout, fulfilment, returns. This is the supported path.

For most merchants.

Agentic
~1 week

Expose a stateful, MCP-equivalent surface for conversational checkout flows.

For brands building their own agent UX.

Ready to ship.

Seven npm packages. Three reference agents. A signed conformance badge. A demo CLI that runs end-to-end flows against any conformant agent. v0.1.0 is live today.

For agent authors

# 1. Clone a reference agent
git clone https://github.com/karannnaidu/Openkarta.git
cp -R packages/reference-agent-shop packages/agent-myshop

# 2. Replace the fixtures
$EDITOR packages/agent-myshop/src/fixtures/

# 3. Prove conformance
npx openkarta-conformance \
  --target https://api.myshop.example.com

For consumer agents

# Install the typed client
npm install @openkarta/sdk-node @openkarta/spec

# Discover, search, quote, checkout
import { createClient } from '@openkarta/sdk-node';

const agent = createClient({
  baseUrl: 'https://halcyon-shop.fly.dev',
});
const manifest = await agent.discover();
